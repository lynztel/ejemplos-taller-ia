# Procesar Inbox

Usa esta lista como revisión rápida:

- [ ] ¿Puedo eliminar esta nota?

- [ ] ¿Es un proyecto con resultado concreto? Mover a `01 Projects`.
- [ ] ¿Es una responsabilidad continua? Mover a `02 Areas`.
- [ ] ¿Es conocimiento reutilizable? Mover a `03 Resources`.
- [ ] ¿Ya no está activo? Mover a `04 Archive`.
- [ ] Añadir enlaces y un resumen de una o dos líneas.
